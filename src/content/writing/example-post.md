This is a draft, so it shows up at `/writing/` when running `astro dev` but is
never built for production. Copy this file to start a new post, then set
`draft: false` (or remove the line) to publish it. The "Writing" link appears
in the header as soon as one post is published.

## Formatting

Regular Markdown works: **bold**, _italic_, [links](https://astro.build),
lists, and code.

```ts
const greeting = "hello";
```

> Block quotes work too.
